# 카드 아트 수동 생성 가이드 (AI Studio 무료)

API 무료 티어에는 이미지 생성 할당량이 없지만, AI Studio 웹 화면에서는 무료로 생성할 수 있다.

1. https://aistudio.google.com 접속 → 모델을 **Nano Banana (이미지 생성)** 로 선택
2. 아래 프롬프트를 하나씩 붙여넣어 생성 (비율 1:1)
3. 마음에 드는 결과를 다운로드해서 `public/art/<파일명>` 으로 저장
4. 전부 모으면: `git add public/art && git commit -m "카드 아트 추가" && git push`

앱은 파일이 있으면 자동으로 사용하고, 없는 것은 이모지로 표시되므로 **일부만 넣어도 된다**.
